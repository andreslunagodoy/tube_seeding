# tube_seeding

## About

This repository is the companion to the paper **"Efficient AI-Inspired
Reduction of Feynman Integrals via Tube Seeding"** ([arXiv:2606.xxxxx](https://arxiv.org/abs/2606.xxxxx)),
by Justin Berman, François Charton, Andrés Luna, Matthias Wilhelm, and
Mao Zeng. 

It provides a proof-of-principle implementation of the
**tube-seeding strategy** introduced there.

We use machine learning to discover a new seeding strategy for
integration-by-parts (IBP) reduction of Feynman integrals — a frequent
bottleneck in state-of-the-art calculations in theoretical particle and
gravitational-wave physics. Restricting the seeds to a thin tube-like
region that connects the target integral to the master integrals along a
zigzag path, the resulting seed selection grows only linearly with the
numerator power, whereas existing strategies grow polynomially. 

The scripts here reproduce the paper's benchmarks, including rank-20
reductions of non-planar 2-loop 5-point integrals with numerical
kinematics over a finite field, and the reduction of complete sets of
top-level rank-10 integrals via division into chunks that can each be
solved with the sparse seeding strategy at considerably lower memory
footprint.

## Installation

First, clone this repository.

Now follow either option 1 (local Python package installation) or option 2 (Docker).
We assume a Unix-like environment to run Bash scripts.

### Option 1: Local Python package installation

Install local and external Python packages (using your favorite Python environment
manager, such as `venv`, `uv`, or `pyenv`):
```bash
pip install -e ./FeynGym/pyfeyngym
python FeynGym/pyfeyngym/install_julia_packages.py
pip install -e ./FeynGym/ppo_masking
pip install torch cma notebook pulp
```

Remember to activate the Python environment for subsequent instructions.

### Option 2: Build Docker image

For this option, you need to have basic familiarity with Docker.

Next build the Docker image
```bash
docker build -t tube_seeding_paper .
```

## One-loop bubble integrals

### Reinforcement learning

The notebook `FeynGym/examples/pyfeyngym_multitarget.ipynb` carries out reinforcement
learning (RL) training. The RL algorithm is proximal policy optimization (PPO), using
convolutional neural networks (CNNs) as actor and critic networks. At the end of the
notebook, the agent tests generate images and animations illustrating the optimized
IBP reduction steps.

### Evolutionary strategies

Under `bubble/`, run `run1.sh` and `run2.sh` for [CMA-ES](https://pypi.org/project/pycma/)
training under two different cutoff schemes for the initial seed candidates.

Then run `plot.sh` to generate plots `bubble_ibp_eqs_scheme1.png`
and `bubble_ibp_eqs_scheme2.png`.

The training graph can be generated by `plot_cma_es_training.py`.
The graph is in the file `cma_es_training.png`.

### Coding agent

The sub-directory `bubble/Google_AI_Studio_Transcript/` contains the transcript of a coding-agent
session (Google AI Studio, based on Gemini) that independently re-discovered the
tube-seeding strategy for the one-loop bubble, using the numerical values
$p_1^2 = 1$, $m = 3$, $D = 13$, additionally with arbitrary master-integral values
$I_{1,0} = 17$, $I_{0,1} = 23$, $I_{1,1} = 37$ to make the linear system completely
numerical. The files are `transcript.json` (raw), `transcript.md` (Markdown translation),
and `transcript_shortened.pdf` (PDF summary of user prompts and final responses).


## Two-loop non-planar double pentagon integrals

For a self-contained introduction, open the notebook
`doublePentagon/gen_eqs_and_solve.ipynb`, which walks through the basic
`pyfeyngym` workflow on this topology without producing any paper result.

### Evolutionary strategies

Under `doublePentagon/evolutionary_strategies`, run `run_cma_es.sh` for CMA-ES
training to find an optimal seed ordering for reducing `(1,...,1,0,0,-12)` on
the maximal cut. The optimization uses a small neural network whose weights are
tuned by CMA-ES; results are written to `maxhigh/resorted_seed_op_list.txt` and
rendered as a 3-D seed figure in `maxhigh/seeds.png`. `cma_es_seed_selection/`
in the same directory contains similar scripts for multi-ISP targets — these
optimize which seeds to include rather than how to order them, again using a
small neural network scored by whether the modular IBP solve closes.

### Rank-20 reductions

The notebook `doublePentagon/rank20/high_rank.ipynb` reduces the single-ISP
target `(1,...,1,0,0,-20)` and the three-ISP target `(1,...,1,-8,-6,-6)` on the
quadruple cut `[1,3,6,8]`, corresponding to Sec. 4.2.4 and Sec. 4.3.2
respectively. `run_all_cuts.sh` in the same directory runs the full 3-ISP
rank-20 reduction across all 11 spanning cuts, using `combined_solve.py` which
internally calls `high_rank_one_cut_firstpass.py` and
`high_rank_one_cut_secondpass.py` to build the seed set in two passes.

### Rank-10 reductions

`doublePentagon/rank10/` contains experiments reducing all 66 rank-10 targets
`(1,...,1,-l,-m,-n)` with `l+m+n=10`, sharing a common seed-construction module
`path_coverage_rank10.py`. `all_rank10_quad/` reduces each target individually
on a quadruple cut (App. B); `all_rank10_cover/` determines which tube paths
cover which targets and finds a bottleneck-optimal five-path cover for the
quadruple cut; `all_rank10_spanning/` extends the coverage analysis to all 11
spanning cuts. The heavy solves are memory-intensive; pin workers to individual
cores and monitor available memory.

### Benchmarks

`doublePentagon/benchmarks/` reproduces the timing and memory scaling tables
and plots of Sec. 4.2.3–4.2.4. `scan_n_feyngym_metrics.py` measures how seed
count, equation count, and peak memory grow with the numerator rank `n` for tube
seeding; `scan_n_paper_metrics.py` runs the same comparison side by side with
conventional decreasing-rank seeding. `scan_triple_cuts.py` and
`run_phase2_pinned10.sh` extend the scan to all ten triple spanning cuts.

### Subsector-exception optimization

`doublePentagon/optimize_seeding/` implements the subsector-exception search of
Sec. 4.2.5. Starting from a uniform tube with `s_max=2`, the scripts walk
through subsectors in order of how many propagators are uncut and find, for each
one, the smallest seeding rank that still closes the reduction — re-solving the
full system at every step. The resulting per-subsector exceptions make the
optimized strategy grow more slowly with rank than the plain `s_max=4` tube.

### Finite-field validation

`doublePentagon/validation/validate_tube_reduction.py` checks that tube seeding
gives the genuine reduction and not a finite-field artifact. It reduces
`(1,...,1,0,0,-n)` on the quadruple cut at several primes and kinematic points,
verifying that the target closes with no extra survivors and that the master
coefficients agree term by term with those from the much larger decreasing-rank
seed set.

### Generation of equation templates

The file `doublePentagon/IBP_LI` — the IBP and Lorentz-invariance equation
templates used by all experiments — is included in the repository but can be
regenerated from scratch using [Kira](https://gitlab.com/kira-pyred/kira) via
the scripts in `doublePentagon/kira_equation_template_generation/`. This is
also the starting point for adapting the code to a new topology.

See `doublePentagon/README.md` for full instructions.

## README file index

Below is a summary of all README files found in this repository, organized by
directory, which give more detailed subject-specific information than this one.

### `bubble/README.md`
Detailed workflow for IBP ordering optimization of **one-loop massive bubble integrals** using CMA-ES.
- **Run 1** (`run1.sh`): triangular seed region (`a1 + a2 ≤ 12`)
- **Run 2** (`run2.sh`): rectangular seed region (`a1 ≤ 6, a2 ≤ 6`)
- **`plot.sh`**: visualizes the NN-optimized seed orderings.
- Covers the full pipeline: seed generation, equation generation, neural network pretraining (3-layer MLP), CMA-ES optimization, and output artifacts.
- Documents all parameters (`n_indices`, `r_max`, `d_max`, `target_integral`, etc.).

### `doublePentagon/README.md`
Detailed workflow for IBP reduction of **massless nonplanar double pentagon integrals**.
- Directory layout for the `doublePentagon/` tree.
- Full instructions for all experiments: CMA-ES seeding, rank-20 reductions, rank-10 coverage, benchmarks, subsector optimization, and validation.

### `FeynGym/README.md`
Main FeynGym README. Reinforcement learning environment for IBP reduction.
- Subfolders: `FeynGym.jl` (Julia package), `pyfeyngym` (Python interface), `ppo_masking` (PPO with action masking).
- Installation instructions for local packages and Julia dependencies.
- Links to example notebooks: `pyfeyngym_multitarget.ipynb` (PPO training), `ppo_masking_example.ipynb`, `pyfeyngym_test_ibp_cost.ipynb`, `IBPEnv_example.ipynb`.
- Docker build and run instructions with GPU support.

### `FeynGym/pyfeyngym/README.md`
Python tools for IBP reduction experiments.
- **Gymnasium environment** (`pyfeyngym-v0`) for RL on the one-loop massive bubble.
- **Equation generation** helpers for arbitrary integral families from Kira-style template files.
- **Julia solver wrappers** for finite-field linear solvers in `FeynGym.jl` and `SparseSolveExact.jl`.
- **`optimize-ordering-NN`** CLI tool for NN/CMA-ES optimization of equation and variable orderings.
- Installation and usage examples.

### `FeynGym/ppo_masking/README.md`
Documentation for the `ppo_masking` Python package (forked from CleanRL).
- Action-mask contract: environments should return `info["action_mask"]` from `reset()` and `step()`.
- Network requirements: actor returns logits `(batch, n_actions)`, critic returns values `(batch, 1)`.
- Minimal example with `ThreePositionEnv-v0`.

### `FeynGym/SparseSolveExact.jl/README.md`
Julia package for solving sparse linear systems over exact fields (finite fields) via Gaussian elimination.
- Provides sparse row/column vector types, finite-field arithmetic (`FF{p, T}`), sparse pivoting heuristics.
- `solve_eqs(equations, variables)` high-level API returning replacement rules.
- Powers IBP reduction for generic topologies beyond the one-loop bubble.
